01 · The event and what Nokia gets

Two days with 200 of the region's strongest young programmers

Human in the loop

Students build AI agents that reason, plan and act, with a person guiding, approving or correcting them at the points that matter. The agent proposes, the human decides. That is how the agent systems that work in production are built: a coding agent that opens a pull request for review, a network agent that proposes a change and waits for an engineer to approve it.

Teams get Cursor with frontier models and API access, choose their own stack, and ship a working demo by Sunday noon. No fixed problem list. A Nokia Challenge track for teams that want a problem from Nokia's world.

Why this fits Nokia Timisoara. The campus employs about 1,300 people, roughly 600 of them R&D engineers, and hires mostly from UPT. The 140 high school students in the room are the UPT intake of 2027 to 2029. The 60 university students are hires of 2027.

Nokia Challenge track: Nokia picks one of these two briefs

  • Incident triage with approval. An agent reads alarms and logs from a simulated network, proposes a diagnosis and a fix, and waits for an engineer to approve before acting.
  • Configuration review. An agent reviews a proposed configuration change, explains the risk in plain language, and asks the human the one question that decides it.

Nothing runs on Nokia infrastructure. Tooling runs on participants' laptops against the providers' APIs, so Nokia's internal restrictions on cloud agents do not touch the event.

03 · The $20,000 credits line

Why $100 and not $10

A chat app that calls a model once per message costs cents. An agent turns one task into dozens of model calls, each carrying the whole context of the code so far. A team using a frontier model in an agentic coding tool for two days burns through $50 to $150 of usage at list prices. Cursor's own plans show the scale: the $20 plan includes $20 of model usage, the $60 plan $70, the $200 plan $400. We size the pool so a team does not run dry on Saturday evening, and keep a reserve instead of giving everyone the maximum.

With no credits at all, every team can still build on the providers' free tiers (Gemini, Mistral, Groq, GitHub Models). The credits are what put frontier models and an agentic coding tool in their hands.

What this means for Nokia. Any credits granted by Cursor or a model provider reduce the cash Nokia spends on this line, one for one, and the final split is in the post-event report. Nokia's package does not grow if the applications fail.

What Cursor can and cannot do

  • Cursor grants credits to hackathons "that meet our criteria", case by case. No published amount; recent events got $50 per participant, or prize credits of $500 to $3,500.
  • Cursor's free year for students closed to new sign-ups in June 2026. Cursor does not sponsor food, prizes or venues.
  • Nokia's own Cursor licences stay out of it: cloud agent features are restricted on Nokia's network. The event runs its own workspace.
