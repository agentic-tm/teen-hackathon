The hackathon

Human in the loop

Students build AI agents that reason, plan and act, with a person guiding, approving or correcting them at the points that matter. The agent proposes, the human decides.

Why this theme

The agent systems that work in production today are the ones that keep people in control: a coding agent that opens a pull request for review, a support agent that drafts a reply for an operator, a network agent that proposes a change and waits for an engineer to approve it. Teaching students to design that boundary from their first project is the point of the event.

Teams get developer tooling (Cursor with frontier models) and API access, choose their own stack, and ship a working demo by Sunday noon. There is no fixed problem list. There is a Nokia Challenge track for teams that want a problem from Nokia's world, for example an agent that triages network incidents and proposes fixes an engineer signs off on.

Why Nokia

What the Title Partner gets

Employer brand where hiring happens

A Nokia keynote on Friday, Nokia engineers as mentors on Saturday and a Nokia Challenge award on Sunday put the company in front of them as the place where this kind of engineering happens.

The Nokia Challenge track

Nokia defines one problem from its own domain and teams opt in. Two examples we would propose:

  • Incident triage with approval. An agent reads alarms and logs from a simulated network, proposes a diagnosis and a fix, and waits for an engineer to approve before acting.
  • Configuration review. An agent reviews a proposed configuration change, explains the risk in plain language, and asks the human the one question that decides it.

Nokia engineers judge this track and hand out the award. Winning projects come with a short write-up Nokia can reuse internally.

Budget · developer tooling credits

The $20,000 credits line, split

$100 per participant, $200 per team, 200 participants. Here is what that buys and why the number is what it is.

ComponentPer personTotalWhat it is
Cursor seat, Teams plan, one month$40$8,000Central billing, spend limits per seat, admin can see usage. Includes Cursor's own usage allowance and unlimited Auto mode.
Frontier model usage at API rates$50$10,000Claude, GPT and Gemini calls made through Cursor or through the team's own API key. This is the pool that empties on a hackathon weekend.
Reserve for the final-day crunch$10$2,000Topped up only for teams that run dry on Sunday morning. Unused reserve is not spent.
Total$100$20,000€17,200

Why $100 and not $10

A chat app that calls a model once per message costs cents. An agent turns one task into dozens of model calls, each carrying the whole context of the code so far. A team using a frontier model in an agentic coding tool for two days burns through $50 to $150 of usage at list prices. Cursor's own plans show the scale: the $20 plan includes $20 of model usage, the $60 plan $70, the $200 plan $400. We size the pool so a team does not run dry on Saturday evening, and keep a reserve instead of giving everyone the maximum.

How the credits are handed out

  • Seats live in one Cursor Teams workspace owned by the organizers, one per participant for the event month. Central billing, per-seat spend limit, no card from any student.
  • Model usage comes from the workspace pool with a hard cap per seat. Teams that want raw API access get a key through a gateway on a UPT server, with the same per-team budget.
  • The reserve is released on Sunday morning to teams close to their cap.
  • With no credits at all, every team can still build on free tiers and on open-weight models served from the UPT and UVT GPU clusters. The credits are what put frontier models in their hands.

Risks and next steps

What could go wrong, and what we do about it

RiskWhat we do
Cursor and the model providers grant nothingThe budget assumes exactly that (scenario A). Any grant is upside. Free tiers and the university GPU clusters guarantee every team can build regardless.
The date slips to JanuaryBoth weekends are held with the universities. Registration and outreach are sized for either. Sponsor money is not spent before the date is locked.
Minors and accountsSeats are created by the organizers in one workspace, so no student signs a contract or enters a card. Parental consent covers participation and photos. An accompanying teacher per school group, medical assistance on site.
Fewer participants than plannedFood, swag and credits scale with headcount. Unspent credits and contingency are reported and returned or rolled into prizes, as the sponsor prefers.
Teams run out of creditsPer-seat caps stop one team draining the pool. The reserve covers the Sunday crunch. Open-weight models on the cluster are the fallback.
Nokia's internal tooling restrictionsNothing runs on Nokia infrastructure. Nokia's contribution is money, people and a challenge brief.
